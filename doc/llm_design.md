# LLM設計・実装タスク

## 決定事項

### モデル選定
- Gemini 2.5 Flash
- SDK: google-genai (直接呼び出し、LangChainは使わない)
- コスト目標: 月数千円以内

### テスト環境
- LangSmith をeval基盤として使用
- データセット作成 → アップロード → eval実行で品質確認

### ディレクトリ構成
```
llm_core/
├── prompts/          # プロンプトテンプレート
└── eval/
    ├── datasets/     # テスト用データセット
    └── (アップロード・評価スクリプト)
```

### LLM呼び出しフロー
1. **分類(緊急度判定)**: メッセージ原文 → 緊急フラグ (boolean)
2. **返信文生成**: メッセージ原文 + リスティング情報 → 返信文 (JSON)
   - 緊急フラグが false のもののみ実行
- LINE通知文はテンプレート埋め込みのみ(LLM不要)

### 入出力フォーマット
| 呼び出し | 入力 | 出力 |
|---------|------|------|
| 分類 | メッセージ原文 | boolean (緊急: true / 通常: false) |
| 返信文生成 | メッセージ原文 + リスティング情報 | JSON (返信文) |
