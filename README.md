サマリ: AvaHostの拡張版を作りたい
仮システム名: たびおとAI

概要1.たびおとAIがサブホストとしてAirbnbアカウントに入る2.メッセージボックスを定期的にスクレイピングして、CSの新規メッセージを検知
3.CSの新規メッセージをAIが分析して、アクション
a.自動返信でOKなメッセージの場合
リスティングの情報を元にAIがAirbnbプラットフォーム上で返信する
リスティングに無い情報: (ex. リスティングの場所は夜うるさいですか? )
AIが勝手に考えて良い(責任を持たずふわっと肯定的に返信させる)
公式LINE(たびおとAI 通知アカウント)からホスト(たくみ)に返信内容を通知
ref: https://developers.line.biz/ja/docs/messaging-api/getting-user-ids/
b.手動返信が必要なメッセージ(苦情や緊急度が高いもの: 鍵が開かない、髪の毛が落ちていた、火災が起きた etc...)の場合
AIが公式LINE経由でホスト(たくみ)のLINEに通知
「xxxさんからxxxの物件について緊急度の高い連絡が届きました。Airbnbを確認してください」
ホストがAirbnbプラットフォーム上で手動返信する。
